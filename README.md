# FSD Technology Demos
A collection of small, practical demonstrations created while learning **Full Stack Development (FSD)**.
This repository contains individual examples of web technologies, HTML5 APIs, JavaScript features, and other concepts covered during the course. The demos are kept simple so that each technology can be understood and tested independently.

## Technologies & Topics
The repository may include demonstrations of:
* HTML5 APIs
* CSS and responsive design
* JavaScript
* Browser APIs
* Web Storage
* Multimedia
* Canvas
* Geolocation
* File handling
* Notifications
* Other Full Stack Development concepts

## Current Demos
| Demo                  | Technology      |
| --------------------- | --------------- |
| `audio_sample.html`   | HTML5 Audio     |
| `canvasapidemo.html`  | Canvas API      |
| `geolocationapi.html` | Geolocation API |
More demonstrations will be added as the FSD course progresses.

## Purpose
The purpose of this repository is to maintain simple working examples of the technologies learned during Full Stack Development and to serve as a reference for future projects and practical work.

## Note
These are **learning and demonstration applications**, not production applications. Each example focuses on demonstrating a particular web technology or concept.
